03

Execution & Workflow

Define the Agent

Declare intent in plain JSON. TeamWeave resolves the right model, tools, and routing rules automatically.

Route & Plan

Step Functions maps the task graph. Parallel branches execute concurrently; retry policies and timeouts are infrastructure concerns.

Execute with Tools

ToolWeave translates natural language into signed REST calls. Each tool invocation passes through risk scoring before commit.

Observe Everything

mcp-observatory captures every PROPOSE/COMMIT pair. Structured logs, risk scores, and latency traces flow to CloudWatch & SIEM.

04

About AIWeave

AIWeave is an ecosystem of open-source, AWS-native AI infrastructure tools built for engineers who need production-grade AI systems without proprietary lock-in.

Every library is composed on AWS primitives: Lambda, Bedrock, Step Functions, DynamoDB, EC2 Spot, API Gateway, S3, and Neptune. Built natively using Tantu React Design Library Components.
